سایت نمایشگاه — Animation Week · انیمیشن و معماری

ساختار
  index.html        صفحه‌ی سایت (صفحه‌ی اصلی، صفحه‌ی هر اثر و صفحه‌ی کیوآرکدها)
  data/works.js     همه‌ی متن‌ها و فهرست آثار — فقط همین فایل ویرایش می‌شود
  media/            عکس‌ها و ویدیوهای آثار
  assets/           ظاهر و کد سایت

نشانی صفحه‌ها
  صفحه‌ی اصلی      https://YOUR-SITE/
  صفحه‌ی هر اثر    https://YOUR-SITE/#work-01   (همان نشانیِ داخل کیوآرکد)
  کیوآرکدها        https://YOUR-SITE/#qr        (چاپ: چهار کارت در هر برگه‌ی A4)

انتشار
  کل این پوشه را روی هر هاست ساده (هاست اشتراکی، GitHub Pages، Netlify و …) بارگذاری کنید.
  بعد نشانی نهایی را در data/works.js در بخش url بنویسید تا کیوآرکدها درست ساخته شوند.
  بعد از چاپ کیوآرکدها، id آثار را عوض نکنید.
